# 拾图 Shitu

<img src="docs/icon/ic_launcher_512.png" width="88" alt="拾图图标">

**把手机里藏起来的图片，自动搬进你自己的文件夹。**

[![License](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/Landslide3154/shitu-android)](https://github.com/Landslide3154/shitu-android/releases)

下载：[最新版 APK](https://github.com/Landslide3154/shitu-android/releases)　·　包名：`com.landslide.shitu`

---

## 它解决什么问题

很多 App 会把图片藏在 `Android/data/<包名>/…` 里——普通应用点不进去，相册里也看不到。
拾图做的事很简单：**每隔几分钟看一眼你指定的文件夹，把新的图片搬到另一个你指定的文件夹**，搬完相册里就有了。

## 两种用法，选一种就能跑

| | 能搬哪里 | 需要准备什么 |
| --- | --- | --- |
| **普通模式** | 相册、下载、Pictures、DCIM 这些普通文件夹 | 在「设置 → 存储访问」里打开「所有文件访问」 |
| **Shizuku 模式** | 再加上 `Android/data` 里 App 私藏的图片 | 装好 [Shizuku](https://shizuku.rikka.app/) 并授权 |

不用二选一：**有 Shizuku 就自动用 Shizuku，没有就用普通模式**，随时切换，不用重装。
唯一的区别是——不装 Shizuku 时，`Android/data` 里面的图搬不了（系统不让我们进）。

## 安装

1. 打开 [Releases](https://github.com/Landslide3154/shitu-android/releases)，下载最新的 `shitu-<版本>.apk`
2. 点它安装（第一次会问「允许安装未知应用」，同意就行）
3. 打开「拾图」

> 要用 Shizuku 模式的话，先装 Shizuku 并启动它；装完回来打开拾图，顶部会显示「Shizuku 已就绪」。

## 第一次用

1. 打开拾图，看顶部状态卡：
   - 写「**本地模式**」或「**Shizuku 已就绪**」→ 可以直接用
   - 不是这两种 → 点卡片里的「**自检**」按钮，看哪一项没通；也可以去「设置 → 存储访问」打开「所有文件访问」
2. 点右上角 **`+`** → **空白规则**
3. 填**规则名称**、选**源目录**和**目标目录**（都从 `/sdcard` 开始往下点）
4. 模式先选 **复制**，点 **保存并开始搬运**——保存前会先告诉你「预计会搬多少张」，确认即可
5. 等几分钟，去相册看看有没有新图。确认没问题后，再把它改成 **移动**

> 为什么先复制？复制不动原图，最坏只是多出一份；确认没选错再改成移动，更稳。

## 功能

**界面**

- 手机底部是浮起 Dock（规则 / 日志 / 设置）；「外观与语言 → 导航栏样式」可以切回停靠底栏；平板、折叠屏展开和横屏自动换成左侧栏。
- 主题中心：跟随系统 / 浅色 / 深色、纯黑、8 个主题色 + 自定义取色、鲜明 / 着色 / 柔和 / 单色、文字大小 80%–140%、标签动画。
- 删除、清空这类操作统一用红色确认框；常用开关和确认带轻微触觉反馈。

**规则**

- 顶部概览卡：左边是通道状态和「自检」按钮，右边是累计搬运 / 本周 / 启用规则；右上角菜单里能打开本周统计。
- 每条规则一张卡：开关管启停，点卡片进编辑；长按有「复制一条 / 撤回已搬的图 / 恢复运行 / 删除」。
- 搜索框按名称 / 源目录 / 目标目录找规则；菜单进入多选后，可批量开启、暂停、删除。
- 菜单「排序」进入后拖动右侧手柄调顺序；也可以上移 / 下移，顺序会记住。
- 简略模式一行一条，一屏看更多；详细模式把源目录 / 目标目录拆成两行。
- 「移动」是绿色、「复制」是蓝色（连圆点和状态胶囊一起）。

**编辑规则**

- 六块：规则名称 / 源目录 / 目标目录 / 移动模式 / 频率 / 文件名。
- 顶部有返回和「保存并开始搬运」；保存前先试运行，算一遍会搬多少张、约多大。
- 只看最近 N 天、只搬至少 N KB 的图（跳过缩略图和表情包）。
- 目标目录可以按 App 名分子目录（`DCIM/起点读书/…`）。
- **按内容重命名文件名（15 位乱码）**：同一张图永远同名，重复出现不会多存一份。
- 有「频率」兜底：平时源目录一变十几秒内就搬，这里只是最长多久强制扫一次。

**日志**

- 每条日志带目标图片的缩略图；「已移动」绿色、「已复制」蓝色；点一条看完整路径和失败原因。
- 点搜索框会列出规则用过的路径和上级目录，点一条直接搜；右侧 ✕ 一键清空。
- 「筛选」按结果和规则过滤；工具栏可暂停刷新；「导出」存成 CSV。
- 跳过重复图片这种「什么都没发生」的事不写日志，只计数。

**设置**

- **运行条件**（可调优先级，**从上到下先命中先算**）：充电时搬 / 锁屏超过 X 分钟不搬 / 电量低于 X% 时不搬 / 亮屏时搬 / 锁屏时搬。默认顺序：充电 → 锁屏超时 → 电量低 → 亮屏 → 锁屏；全关 = 任何时候都搬。
- **检测时机**：亮屏加速检测、写完就搬。
- **运行参数**：扫描预算、每次 / 每分钟上限、日志保留等，默认值适合大多数手机。
- **存储访问**：普通模式的授权入口。
- **复制记录**：点开能看到每张已复制图片的缩略图，勾选后只清掉选中的。
- **设置管理**：规则和各项设置一起导出备份；导入时可以只恢复规则、只恢复设置，或两者都恢复。
- **外观与语言**：主题中心、导航样式、标签动画、文字大小；语言跟随系统 / 汉语 / English 随手切。
- **通知**：暂停、Shizuku 未就绪、撤回结果等提醒的总开关。
- **自检**：检查存储权限、Shizuku 连接和数据库，结果可复制。
- **检查更新**：有新版可直接下载安装；后台每天最多自动查一次，有新版本会主动发通知。

**快捷方式**

- 长按桌面上的拾图图标，可以直接「立即搬运」「打开日志」「打开设置」。

## 扫描与搬运节奏（放进去多久会搬）

先看结论：

| 手机状态 | 放图后大概多久搬走 |
| --- | --- |
| **亮屏且已解锁**（App 在前台或后台都一样） | **10–20 秒** |
| **刚锁屏的几分钟内**（还没深睡） | **30–60 秒** |
| **锁屏很久、手机已经深睡** | 等下一次闹钟，**可能几分钟，最多约 10 分钟** |
| **图放在很少用的子目录里** | 等整条规则完整扫一遍，**默认 5 分钟**（可设 1–30 分钟） |

> 一句话：亮屏最快；锁屏前几分钟也快；锁屏久了手机会深睡，只能等闹钟。

### 为什么锁屏久了会变慢

- 锁屏后的前几分钟，App 每 30 秒看一次源目录，所以新图一般 30–60 秒就搬走。
- 大约 4 分钟后（不同手机略有差异），Android 会让手机进入**深睡（Doze）**，把 30 秒的定时器停掉；这时只剩 App 的 **10 分钟闹钟**能叫醒它。
- 闹钟按固定节奏排，所以放图时离下一次闹钟多久，就要等多久：**几分钟到 10 分钟都正常**，不是 App 卡住。
- 小技巧：看常驻通知里的「上次」时间；如果它不再每分钟更新，通常就是已经深睡了。

### 插电 / 连电脑为什么看起来更快

- **App 的扫描频率和是否充电无关**：充电只影响「充电时搬」这个运行条件，不会让扫描变快。
- 但**插着电、连着电脑调试时，手机通常更晚进入深睡**，所以看起来更快；拔电后深睡更早，等闹钟的时间可能更长。用电脑测出来的 10–20 秒 / 30–60 秒，只代表「定时器还在跑」的时候。
- 想让拔电锁屏也一直保持 30–60 秒，只能让 App 在锁屏后保持清醒，会更耗电；默认没有开。

### 其他会影响时间的因素

- **运行条件不满足**时完全不扫（通知会写原因）；条件恢复后的下一拍继续。
- 文件要**确认写完**才搬：默认两次观察间隔 ≥3 秒、大小/修改时间不变；还在下载的会等（最多约 30 秒）。
- **规则完整扫描**默认每 5 分钟一次；快检盯不到的深层子目录，最多等一个规则间隔。
- 目标已有同内容、规则暂停/出错、扩展名/大小/天数过滤、没 Shizuku 进不去 `Android/data`，会跳过或失败。

## 常见问题

**搬不动、一张都没搬？**

先点顶部状态卡里的「自检」按钮，看哪一项红了；再看日志里的失败原因。

**日志是空的？**

说明还没有真正搬过东西：确认规则开关是开着的，再等它下一轮自动扫描（打开 App 后会自动跑一轮）。

**会不会删我的图？**

不会。搬失败时源文件保持不动；移动模式下搬完发现不对会自动退回原位；而且**永远不覆盖**已有文件。

**怎么换成英文界面？**

设置 →「外观与语言」→ English；想换回来点「汉语」。不用改系统语言。

**怎么知道有没有新版本？**

「设置 → 关于 → 检查更新」手动查；后台每天也会自动查一次，有新版会发通知。只有这一个功能会联网，其余全部离线。

**后台老被杀？**

HyperOS / MIUI 需要做四件事：允许「自启动」、省电策略设「无限制」、最近任务里加锁、允许通知。

**想搬 `Android/data` 里的图，但没装 Shizuku？**

这个目录系统只允许 Shizuku（或电脑 adb）这种身份进去，换成 Shizuku 模式才行。

## 隐私

- 除了「检查更新」会访问 GitHub（后台每天最多自动查一次），**其余功能一律不联网**
- 图片只在你指定的两个文件夹之间搬，不上传、不分析内容
- 日志和设置只存在手机本地；导出的 CSV 和备份文件含完整路径，分享前留意
