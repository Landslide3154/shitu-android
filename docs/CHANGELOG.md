# 更新日志

## 0.20.10 — 2026-10-18

**运行条件可以排优先级；新增「锁屏超过 X 分钟不搬」**

- 运行条件改成统一优先级列表：从上到下先命中先算。允许条件（充电/亮屏/锁屏）命中就搬，阻止条件（锁屏超时/电量低）命中就停。
  默认顺序：充电 → 锁屏超时 → 电量低 → 亮屏 → 锁屏。充电放最上面 = 充电优先；用 ↑↓ 把它排到下面，电量低/锁屏超时也能拦住充电。
- 新增「锁屏超过 X 分钟不搬」：默认 30 分钟，可设 1–240 分钟；解锁后重新计时。
- 修了充电判定的一个坑：充电保护/旁路供电时系统会报「没在充电」，但实际插着电；现在按「是否插电」算，充电条件更可靠。
- 深度休眠优化：锁屏久了系统会暂停定时器；现在每 10 分钟用闹钟唤醒一次补扫，扫描时短时持有 WakeLock，不会搬一半被冻住。

## 0.20.9 — 2026-10-18

**锁屏后新图也会及时搬，不用等 5 分钟或打开 App**

- 「熄屏时搬」改名为「锁屏时搬」：锁屏和息屏按同一个状态算（屏幕熄灭或停在锁屏界面都算锁屏）。
- 锁屏后也跑「快节奏检测」：每 30 秒只看一眼源目录有没有变，变了就立刻扫，不再干等规则自己的 5 分钟间隔；
  亮屏时仍按设置的间隔（默认 10 秒）。
- 完整扫描照旧每 30 秒做一次（按规则间隔），所以嵌套目录、条件不满足期间产生的图片也会补上。
- 运行条件仍是「满足任意一条就搬」；充电时不受电量/省电限制。

## 0.20.8 — 2026-10-18

**后台会自己搬了；有新版本会主动提醒**

- 修掉「App 切到后台就不搬图、打开 App 才搬」的问题：运行条件改成**满足任意一条就搬**。
  比如同时勾了「充电时搬」和「亮屏时搬」，以前要两个同时满足——熄屏充电时永远等不到亮屏，一张都不搬；
  现在插着充电器就会搬，亮屏时也会搬。同理，「亮屏 + 熄屏」一起勾 = 任何时候都搬。
- 亮屏时除了快速检测，也会按规则间隔做完整扫描：嵌套目录里新增的图片、以及条件不满足期间出现的图片都能补上，
  不再只靠「打开 App 立即扫一次」。
- 插着充电器时不再受「电量低于 X%」和省电模式限制（和设置页说明一致）。
- 旧版遗留的「熄屏后暂停扫描」设置不再生效：它的开关早就从界面移除了，但旧设置里如果还是开着的，
  会悄悄盖掉「充电时搬」，看起来就像 App 在后台不工作。现在熄屏时搬不搬完全由运行条件决定。
- 新增：后台每天最多自动检查一次更新，有新版本会发通知；点通知直接进 App 的更新弹窗，可以看说明并下载安装。
  仍然只有检查更新会联网，其余功能保持离线。

## 0.20.0 — 2026-10-17

**自 0.12.3 以来的第一次正式发布：没装 Shizuku 也能用、能检查更新、支持英文、整个界面重做**

这次不是小补丁。下面按「你会感受到什么」汇总从 0.12.3 到现在的全部变化。

### 1. 没有 Shizuku 也能搬普通目录

- 新增「普通模式」：在「设置 → 存储访问」里打开系统的「所有文件访问」，不装 Shizuku 也能搬相册、下载、
  Pictures、DCIM 这些普通目录里的图；`Android/data` 里的图仍然需要 Shizuku（系统限制）。
- 有 Shizuku 时优先用它，掉线会自动退回普通模式，不用重装、不用改规则；两条都不通时界面会直接说缺什么。
- 自检和目录选择器都走当前可用的通道，不会再因为「没装 Shizuku」整个 App 不可用。

### 2. 检查更新，并且可以直接装

- 「设置 → 关于 → 检查更新」：联网查 GitHub 最新版，有新版会显示更新说明。
- 可以直接「下载并安装」，不用再跳浏览器（第一次会让你允许安装未知应用）。
- 这是全 App 唯一联网的地方，其余功能仍然完全离线。

### 3. 支持英文，语言随手切

- 界面文案全部抽成资源：系统是英文就显示英文，中文系统保持中文。
- 也可以手动切：「设置 → 外观与语言 → 跟随系统 / 中文 / English」，切完立刻生效，不用改系统语言。

### 4. 规则编辑重做：六张卡、可试运行

- 分成六块：规则名称 / 源目录 / 目标目录 / 移动模式 / 频率 / 文件名，一眼看得懂。
- **保存前先试运行预览**：告诉你预计会搬多少张、约多大、其中多少张目标里已有同名文件；也可以随时手动预览。
- 新增条件：只看最近 N 天的图、只搬至少 N KB 的图（跳过缩略图、表情包）。
- 目标可以按 App 名分子目录（`DCIM/起点读书/…`），不同 App 的图不混在一起。
- 「按内容重命名文件名（15 位乱码）」：同一张图永远同名，重复出现不会多存一份；可以和后缀叠加。
- 每个功能尽量配一句小字说明；只有真正需要解释的（子目录、过滤条件、试运行）才留一个 ⓘ。

### 5. 日志更好用

- **不再刷屏**：复制模式里「这张图已经复制过」的跳过不再写日志，只计数；同一个文件第二次扫到直接跳过，也不再重算内容哈希。
- 结果和规则的筛选收进右上角「筛选」面板，日志列表多出十几行空间。
- 每条日志左边有**缩略图**；「已移动」是绿色、「已复制」是蓝色，一眼区分。
- 点搜索框会列出规则用过的路径和上级目录，点一条就直接搜；右侧 ✕ 一键清空。

### 6. 设置页重组

- 运行条件（可多选）：**充电时搬 / 亮屏时搬 / 熄屏时搬 / 电量低于 X% 时不搬**，全关 = 任何时候都搬；插着充电器时不受电量限制。
- 「检测时机」：亮屏加速检测、写完就搬；「运行参数」折叠在底部，默认收起。
- 复制记录可以点开看缩略图并**挑着删**，也能全部清空。
- 「设置管理」：规则和各项设置一起导出备份，换手机或重装后一次恢复（导入的规则默认暂停）。
- 自检只留一个按钮，点开看结果。
- 存储访问的说明和按钮放在同一行，已授权时按钮是绿色的。

### 7. 界面与细节

- 规则卡：「移动」绿色、「复制」蓝色（连圆点和状态胶囊一起）；详细模式去掉了「立即运行」「编辑」两个按钮——点卡片就进编辑。
- 顶部「本周 +N 张」统计，点开能看本周搬了多少、失败多少、来源最多的 App。
- 目录选择器重做：统一的圆角卡片、当前路径单独一块、文件夹一行一行点进去。
- 名称改得更直白：子目录层数、只看最近 N 天、至少多大 (KB)、检查频率、文件类型、加后缀。
- 修了一个分页漏洞：源目录文件多、需要分页扫描时，游标停在子目录上会漏掉整棵子树。
- README 重写，带界面截图；详细说明移到 `docs/使用手册.md`。

> 升级不会动已有规则和文件；「普通模式」要手动去系统设置里授权一次。

## 0.12.4 — 2026-10-17

- **没有 Shizuku 也能用**：以前所有文件操作都靠 Shizuku。现在多了一条「普通模式」——在「设置 → 存储访问」里打开系统的

## 0.1.0 — 2026-10-04

首个可用版本。借 Shizuku 的 shell（adb）身份，把 `Android/data/<包名>/...` 这类普通 App 进不去的目录里的图片，自动搬到指定目标目录。

### 功能

- **规则化搬运**：源目录（可含子目录、可限深度）→ 目标目录；每条规则独立开关与间隔（1–30 分钟）
- **移动 / 复制两种模式**，默认移动；首次使用建议先复制试一天
- **全自动**：`specialUse` 常驻前台服务按间隔轮询 + 打开 App 立即扫一次 + WorkManager 15 分钟兜底
- **命名安全**：非法字符清洗、来源 App 后缀（如 `封面_起点读书.png`）、超长截断（180 字节）、冲突时加时间戳/序号，**永不覆盖**
- **绝不误删**：任何失败源文件保持不动；移动模式校验失败会自动把文件移回原位
- **可撤回**：只撤"本 App 搬的、目标未被改动、源位置仍空闲"的记录，不符合条件时逐条说明原因
- **可观测**：运行日志（按规则/结果/关键字筛选）、统计计数、CSV 导出
- **可自检**：一键 6 项检查（Shizuku 通道 / 列源目录 / 目标可写 / 源目录可写改名删 / 源→目标可移动 / 环境信息），只用自己创建的临时文件
- **重复抑制**：同名文件在 30 分钟内被搬走 3 次 → 自动暂停该规则并通知（防"搬走→App 重建"死循环）
- **限速**：单轮 ≤20 张、单轮 ≤60 秒、每分钟 ≤120 张（可在设置里改）
- 界面四页全中文：规则列表 / 规则编辑（含 Shizuku 目录选择器）/ 日志 / 设置

### 技术

- Kotlin + Jetpack Compose + Room + DataStore + WorkManager + Shizuku API 13.1.5
- `minSdk 30 / targetSdk 36 / compileSdk 37`；`FOREGROUND_SERVICE_SPECIAL_USE`，不申请「所有文件访问」，无 INTERNET 权限
- App 进程不直接做任何文件操作，全部经 AIDL 交给跑在 `uid=2000(shell)` 下的 `ShituUserService`

### 实测

- 61 个 JVM 单测 + 12 个真机用例全绿（Redmi K90 Pro Max / Android 16 / HyperOS 3）
- 真机确认：能列/写别的 App 的 `Android/data`；自检 6 项全绿；复制/移动/撤回/不覆盖均符合预期
- 已知限制见 [`docs/2026-10-04-shitu-验证记录.md`](2026-10-04-shitu-验证记录.md)

### 安装与首次使用

1. 侧载本 Release 里的 `app-release.apk`
2. 打开 Shizuku → 给「拾图」授权（App 里点「请求授权」会弹窗）
3. 手机设置 → 应用设置 → 拾图 → **自启动：允许**、**省电策略：无限制**，并在最近任务里加锁
4. App 里新建规则：源目录选 `Android/data/<包名>/...`，目标默认 `/sdcard/Pictures/拾图`，**先用复制模式**
5. 确认目标目录里的图确实是你想要的，再切移动模式

> ⚠️ 系统更新（HyperOS 补丁 / Google Play 系统更新）后可能失效，请先跑一次「自检」。
