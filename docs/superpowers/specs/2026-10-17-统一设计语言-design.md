# 统一设计语言：圆角 / 输入框（0.20.2）— 设计

日期：2026-10-17 · 状态：已实现（0.20.2）

## 用户诉求

1. 新建规则里的输入框「**字太大、框太大、框的圆角太小**」。
2. 整个软件里卡片、输入框、所有带圆角的东西**圆角要统一**；「其他可能也有我没注意的地方」需要自己再盘一遍。

## 现状问题（盘点结论）

- 圆角全是硬编码，同一类东西的值不一样：卡片 18 / 20、对话框 24 / 28、列表行 8 / 10 / 12 / 14、胶囊 50。
- `OutlinedTextField` 共 12 处，全部没设 `shape`（吃 Material3 默认 4dp，所以「圆角太小」），
  也没设 `textStyle`（默认 `bodyLarge` 16sp，所以「字太大」）。
- `Theme.kt` 只有 colorScheme 与 typography，没有 `shapes`，Material3 组件全用默认形状。

## 方案

### 1. 唯一圆角来源 `ui/theme/Shapes.kt`

| token | 值 | 用途 |
| --- | --- | --- |
| `ShituRadius.Card` | 20dp | 大卡片：规则卡 / 设置卡 / 状态卡 / 日志卡 |
| `ShituRadius.Dialog` | 28dp | 自定义对话框（M3 AlertDialog 跟随 Theme 的 extraLarge） |
| `ShituRadius.Field` | 14dp | 所有输入框 |
| `ShituRadius.Row` | 12dp | 列表行 / 小色块 / 弹窗选项行 |
| `ShituRadius.Pill` | 50 | 胶囊标签：状态胶囊 / 模式标签 |
| `ShituRadius.thumb(size)` | size/6 | 缩略图随尺寸等比（没有固定尺寸，不算不统一） |

`ShituShapes` 接进 `MaterialTheme`：`medium = Card`（Card 默认形状）、`extraLarge = Dialog`（AlertDialog 默认）、
`large = Card`（FloatingActionButton 变成 M3 Expressive 的圆角方形）、`small = Row`、`extraSmall = 8dp`（菜单/提示条）。

### 2. 唯一输入框 `ui/components/ShituField.kt`

`OutlinedTextField` 的薄包装：

- `shape = ShituRadius.FieldShape`（14dp，替代默认 4dp）
- `textStyle = MaterialTheme.typography.bodyMedium`（14sp，替代默认 16sp）；placeholder 同步 14sp
- label 收 `String?`（原来是 composable 槽位），trailingIcon / supportingText / keyboardOptions / readOnly 原样透传
- 高度暂保持 Material3 的 56dp 最小高度：不在本轮硬压（硬压会裁文字），真机看过再定

12 处 `OutlinedTextField` 全部换成 `ShituField`（规则编辑页 9、日志页 1、设置页 1、目录选择器 1）。

### 3. 不做的事

- 不改字号层级（卡片标题仍是 titleMedium，说明仍是 bodySmall）与间距。
- 不改按钮形状（Button / OutlinedButton 保持 M3 默认，与胶囊标签区分）。
- 不改文案与交互。
