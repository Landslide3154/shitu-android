## 发版方式的两次定调（原文摘要）

1. 2026-10-04：用户定「**不走 GitHub Actions，就用本机**」。
2. 2026-10-13 追加约束：`gradlew assembleRelease` → 真机装一遍点一遍 → 本地 `git commit` 后**停下**；`git push` / `git tag` / 建 Release **必须等用户明确要求**（用户原话：「以后不要主动推送，只有我要求你推送的时候再推送，每个项目都这样」）。
3. 拿到口令后：`git push origin main` → `git tag vX.Y.Z` + 推 tag → 用 REST 建 Release，附件直接 POST `https://uploads.github.com/repos/<owner>/<repo>/releases/<id>/assets?name=shitu-X.Y.Z.apk`（用 `upload_url` 做正则替换会拼出非法 URI）；token 走 `git credential fill`（本机凭据在 Git Credential Manager，没有 `~/.git-credentials` 文件）。
4. `.github/workflows/release.yml` 只保留 `workflow_dispatch` 应急。

> 2026-10-16 核对：`app/build.gradle.kts` 仍是 `versionCode 22 / versionName "0.12.3"`，`app/src/test` 下 `@Test` 计数仍是 123 —— 与快照一致。

## 2026-10-18 上午快照（0.20.8，发布版）

- 大方向：修「App 挂后台不搬、打开才搬」——三处叠加：多选条件按「且」、旧「熄屏暂停」为 true 时覆盖条件、

  才能走 `adb reverse`，验证完必须还原。
